# Decision record

The fundamental decisions of `@aontu/mod`: the choices the rest of the
repository is built on, which a contributor, person or agent, does not
quietly reverse.

- **Only the maintainer adds an entry.** An agent may propose a
  decision, in a pull request or an issue, but never writes one here.
- **An entry is at most 200 words.** It states the decision, the
  context that forced it, and what it costs.
- **An entry cites no history.** It has no superseded, amended or
  relocated status: a decision that no longer holds is rewritten or
  removed by the maintainer, and version control keeps what it said.
